# Explanation: Divio Content Model

OpenSwarm documentation is organized by user intent, following Divio's model.

## Tutorials

For learning. Linear steps that produce a successful outcome.

## How-to Guides

For doing. Direct recipes for a specific task under real constraints.

## Reference

For lookup. Exact commands, keybindings, paths, and behaviors.

## Explanation

For understanding. Rationale, architecture, and tradeoffs.

## Why This Improves Productivity

- Reduces time spent searching for the right level of detail.
- Matches docs format to user context (learn, do, check, understand).
- Scales better as features and workflows expand.
