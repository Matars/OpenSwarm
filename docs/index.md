# OpenSwarm Documentation

Welcome to the OpenSwarm docs. This documentation follows the Divio model so you can quickly find the right kind of help:

- Tutorials: step-by-step learning paths.
- How-to guides: practical task recipes.
- Reference: exact behavior, inputs, and keybindings.
- Explanation: concepts, design choices, and mental models.

If you are new, start with [First Parallel Workflow](tutorials/first-parallel-workflow.html).

## Quick Start

1. Build and run OpenSwarm:
   - `make dev`
2. Open the worktree view and create your first worktree:
   - Press `a`
3. Open an agent or shell in that worktree:
   - Press `O` for agent picker or `o` for shell
4. Commit and push from the worktree:
   - Press `c`, then `p`
