# How to Create and Manage Worktrees

Use this guide when you need to add, navigate, prune, or remove worktrees.

## Create

- Press `a` in worktree view.
- Choose base: main, selected, or selected with changes.
- Enter branch name and press Enter.

## Navigate

- Arrow keys move selection by graph direction.
- `h` and `l` move siblings on the same depth.
- `j` and `k` move vertically across levels.
- `Tab` cycles canvas/details/actions panes.

## Refresh

- Press `r` to reload worktree data.
- Press `x` to run prune for stale entries.

## Remove

- Press `d` on selected worktree.
- Current worktree cannot be removed.
- Dirty worktrees require confirmation before force remove.

## Tips

- Keep each worktree focused on one objective.
- Prefer short-lived branches for fast merge cycles.
